Spend Control / Setup

Connect Facebook once.

One app. Your authorized business assets.

  1. Create or use your Meta developer app. Enable the Marketing API use case and Facebook Login for Business. Associate the app with the appropriate business portfolio.
  2. Create a login configuration. Choose a User access token configuration so Facebook can identify the workspace owner. Choose the assets and permissions needed for your actual use. A system-user-only configuration cannot be used as human owner sign-in.
  3. Register your HTTPS URLs. Copy the exact redirect URL displayed in Connections to Valid OAuth Redirect URIs. Add this site’s domain, privacy URL, data-deletion callback, and deauthorization callback in the Meta app dashboard.
  4. Save the app ID, app secret, and configuration ID. Enter them in Connections → One-time app setup, then Connect Facebook. First-time setup also requires the workspace setup token from your server.
  5. Choose accounts and Pages. Grant access on Facebook, then select assets in Spend Control. Creating a brand does not automatically start advertising.

Permissions depend on the work

Ad management uses ads_management and ads_read. Page discovery uses pages_show_list and pages_read_engagement. Page ads and forms use pages_manage_ads; lead downloads use leads_retrieval. Business discovery uses business_management, and connected Instagram discovery uses instagram_basic.

Comment handling additionally needs the applicable pages_read_user_content, pages_manage_engagement, pages_manage_metadata, and instagram_manage_comments permissions. Grant these when enabling the related feature and obtain any required Meta reviews and asset tasks.

Your accounts and client accounts

Seeing an asset in Business Suite does not automatically authorize this app. The app’s access level, the permissions you grant, and your role on each asset all apply. Managing other people’s advertising accounts requires appropriate Advanced Access. Meta’s dashboard determines the review and business-verification requirements for your use case.

Background work and recovery

The server keeps encrypted authorization so work can continue after the browser closes. Facebook user authorization has an expiry and can be revoked earlier. Connections displays the reconnect date. If access expires or is rejected, the worker stops new automated work and retains pending campaign pauses. Reconnect promptly and check existing delivery in Ads Manager.

You can add a recovery password under Workspace access. Keep the original workspace setup token and encryption key with your server recovery records.
